# 📖 Sentence Maker

A Mad Libs style story generator built with HTML, CSS, and JavaScript. 
Fill in the blanks with your own words and watch your custom adventure story come to life!

🔗 [Live Demo](https://allan-3.github.io/sentence-maker/)

## Features
- Interactive form with six word inputs
- Dynamically generated story based on user input
- Clean, responsive design
- "Fill Example" button for quick testing
- "Clear" button to reset the form

## Built With
- HTML
- CSS
- JavaScript (vanilla, no frameworks)

## Running Locally
1. Clone this repo: `git clone https://github.com/allan-3/sentence-maker.git`
2. Open `index.html` in your browser (or use the Live Server extension in VS Code)
